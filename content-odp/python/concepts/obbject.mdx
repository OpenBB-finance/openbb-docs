`openbb_core.app.model.obbject.OBBject` is a `Generic[T]` Pydantic model that wraps command results together with provider attribution, warnings, an optional chart, and extension-attached accessors.

Streaming commands return [`OBBStream`](/odp/python/concepts/streaming) instead. The two envelopes are siblings — a router declares one or the other via its return annotation.

## Fields

| Field | Type | Default |
| --- | --- | --- |
| `results` | `T \| None` | `None` |
| `provider` | `str \| None` | `None` |
| `warnings` | `list[Warning_] \| None` | `None` |
| `chart` | `Chart \| None` | `None` |
| `extra` | `dict[str, Any]` | `{}` |

Class-level attributes:

- `accessors: ClassVar[set[str]]` — names of registered accessors. Populated by OBBject extensions.
- `_user_settings`, `_system_settings` — references to the active settings models.

## Accessor methods

| Method | Returns |
| --- | --- |
| `to_df(index="date", sort_by=None, ascending=None)` | `pandas.DataFrame` (alias for `to_dataframe`) |
| `to_dataframe(index="date", sort_by=None, ascending=None)` | `pandas.DataFrame` |
| `to_polars()` | `polars.DataFrame` |
| `to_numpy()` | `numpy.ndarray` |
| `to_dict(orient="list")` | `dict \| list[dict]` — `orient` is one of `"dict", "list", "series", "split", "tight", "records", "index"` |
| `to_llm()` | `str` — JSON-encoded `records` orient of the dataframe form, with ISO date format |
| `show(**kwargs)` | `None` — invokes the chart's `fig.show(...)`. Raises `OpenBBError` if no chart is set. |
| `from_query(query)` (`classmethod`, `async`) | `OBBject` |

There is no `to_chart()` method. Charts are displayed via `show(...)` after a chart has been produced by passing `chart=True` at call time.

## `output_type` preference

When `user_settings.preferences.output_type == "OBBject"`, the `OBBject` is returned as-is. For any other accepted value, the corresponding accessor is called on the `OBBject` before returning. Accepted values:

```
Literal["OBBject", "dataframe", "polars", "numpy", "dict", "chart", "llm"]
```

Default: `"OBBject"`. The model uses `validate_assignment=True`, so an unsupported assignment raises a validation error.
