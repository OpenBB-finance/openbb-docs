<HeadTitle title="OpenBB Python (V5) | OpenBB Docs" />

OpenBB Python is a set of packages built on `openbb-core`. Each provider package connects one data source and adds its own namespace, such as `obb.fred`, `obb.sec`, or `obb.cboe`. The same installed commands are available from Python with `from openbb import obb`, as a REST API, as MCP tools, and as OpenBB Workspace widgets, and extensions you write yourself plug into all of them the same way.

:::important
V5 is a breaking release. Commands move from shared routers such as `obb.equity` into provider namespaces, fifteen V4 provider packages are removed, and the license changes from AGPL-3.0 to Apache-2.0. [Migration from V4](./migration-from-v4.mdx) lists every change. The V4 documentation remains available under [/odp/v4/python](/odp/v4/python).
:::
