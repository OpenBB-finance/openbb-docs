<HeadTitle title="User Guide | OpenBB Python (V5)" />

These guides are for people who call commands, whether through `from openbb import obb`, the REST API, or the MCP server. Each one covers a single task, notes where the surfaces behave differently, and ends with a check you can run. Examples use the FRED provider (`openbb-fred`) with the key set up in [Quick start (User)](../quickstart/user.mdx), plus `openbb-news`, `openbb-nasdaq`, and `openbb-tmx` where a command needs more than one provider.
