`ExtensionLoader.load_core` accepts a `Router`, a `FastAPI` app, or an `APIRouter` registered under the `openbb_core_extension` entry-point group. A FastAPI / APIRouter target is wrapped via `Router.from_fastapi`. From there it's reachable through both surfaces.

## 1. Install

```bash
pip install openbb-core
```

FastAPI and Uvicorn come transitively.

## 2. Write the FastAPI app

`my_extension/app.py`:

```python
from fastapi import APIRouter
from pydantic import BaseModel


class GreetResponse(BaseModel):
    message: str


router = APIRouter()


@router.get("/greet")
def greet(name: str = "world") -> GreetResponse:
    """Return a friendly greeting."""
    return GreetResponse(message=f"hello, {name}")
```

This is an ordinary FastAPI `APIRouter`. It does not import `openbb-core`.

## 3. Register the entry point

`pyproject.toml`:

```toml
[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"

[project]
name = "openbb-my-app"
version = "0.1.0"
requires-python = ">=3.10"
dependencies = ["openbb-core"]

[project.entry-points."openbb_core_extension"]
my_app = "my_extension.app:router"
```

The entry-point name (`my_app`) becomes the namespace on `obb`. The value must point at an already-instantiated `FastAPI` or `APIRouter` — factory callables are not supported.

## 4. Install editable

```bash
pip install -e .
```

## 5. Build the Python Interface

```bash
openbb-build
```

This generates the `obb.my_app.*` methods. See [Packaging and static assets](/odp/python/concepts/packaging).

## 6. Use it

Python:

```python
from openbb import obb

obb.my_app.greet(name="darren")
# GreetResponse(message='hello, darren')
```

REST:

```bash
openbb-api
curl 'http://<host>:<port>/api/v1/my_app/greet?name=darren'
# {"message":"hello, darren"}
```

## Notes

- The Python Interface returns exactly what your handler returns. `SignatureInspector.complete` returns the function unchanged when the return annotation is not an `OBBject` subclass; nothing is auto-wrapped. If you want `to_dataframe()` / `to_polars()` / `to_llm()` on the return, declare your handler's return type as `OBBject[...]` and construct one in the function body. See [The OBBject envelope](/odp/python/concepts/obbject).
- `openbb-build` accepts the `OPENBB_DEBUG_MODE=1` environment variable for verbose output.
